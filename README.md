# ONE WAY DOWN — Content Studio

Public-safe editorial operations PWA for **ONE WAY DOWN**.

## Live app

`https://rodaspinto.github.io/one-way-down-studio/`

## Included

- 14 operational areas;
- 95 individual public-safe image previews embedded in `src/data.js`;
- 14 pre-launch posts;
- seven public chapter records;
- calendar, post editor, ZIP/CSV/ICS export, metrics and backups;
- mobile-first interface installable on iPhone.

## Deliberately excluded

- private canon and unrevealed story material;
- full manuscripts;
- CH-008 and CH-009;
- internal Google Drive links or IDs;
- private audio/video originals;
- future votes and unreleased consequences.

Browser edits are stored in `localStorage`. Export a JSON backup before clearing Safari data or changing devices.

Read `CLAUDE.md` before using Claude or another coding agent on this repository.
